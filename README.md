# Fraud Detection using Machine Learning

This project analyzes and compares different machine learning models for detecting fraudulent transactions in highly imbalanced financial datasets.

## Methodology
The analysis follows a structured approach including data preprocessing, modeling and evaluation using metrics such as recall, precision and F1-score.

## Models evaluated
- Logistic Regression
- Naive Bayes
- Random Forest
- HistGradientBoosting
- Isolation Forest
- Local Outlier Factor

## Key insight
Maximizing recall is critical in fraud detection, as the main objective is to minimize undetected fraudulent transactions.

## Results
HistGradientBoosting achieved the best balance between recall and precision.
